# Project Guidelines & User Preferences

## Communication Rules
- **Software Terms Explanation Rule**: Whenever using any software engineering or technical terminology, acronyms, or concepts (such as APK, ADB, CI/CD, Unit Test, Commit, Build, Repository, Regex, SDK, etc.), always provide a clear, simple explanation directly adjacent to the word (in parentheses right next to the term).
- **Tone & Style**: Clear, structured, encouraging, and transparent.
